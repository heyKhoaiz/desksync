# DeskSync

Notes, read-later, clipboard history and an encrypted password vault — one account across
every Chrome profile and an Android app (`mobile/`, in progress). See `docs/ARCHITECTURE.md` for the full plan.

## Setup (10 minutes)

### 1. Supabase
1. Create a free project at supabase.com.
2. **SQL Editor** → paste `supabase/schema.sql` → **Run**.
   Already had DeskSync running before the redesign? Also run `supabase/migrations/001_tags_and_markdown.sql`
   — `create table if not exists` does not add the new `tags` and `format` columns to tables you already have.
3. **Authentication → Providers → Email**: enabled. (Turn off "Confirm email" while testing if you like.)
4. **Project Settings → API**: copy the Project URL and the `anon` public key.

### 2. Your keys
Run `make env`, then put the Project URL and anon key in `.env` (gitignored).

### 3. Extension
1. `make ext` builds it into `dist/extension`.
2. Chrome → `chrome://extensions` → turn on **Developer mode** → **Load unpacked** → pick `dist/extension`.
3. Pin DeskSync, create an account, done.
4. In each other Chrome profile: load the same folder and sign in with the same account.

After changing extension code, run `make ext` again and click reload on the extension's card.

### 4. Android app
Plug in a phone with USB debugging on, then run `make app`. See `mobile/README.md`.

### Commands
Run `make` to list them all: `env`, `ext`, `zip`, `icons`, `app`, `apk`, `devices`, `test`, `test-ext`, `clean`.

## Use
| Action | How |
|---|---|
| Open | click the icon or `Alt+Shift+D`. The popup opens with the cursor in the search field |
| Find anything | just type — one search covers notes, links, clipboard and vault. Arrow to move, Enter to open |
| Filter by type | the rail down the left, or `Ctrl+1` to `Ctrl+5` |
| Filter by tag | click a chip, or type `#tag` in the search field — they are the same thing |
| Tag something | select it, then *+ Tag* in the pane on the right. Works on all four types |
| Rename or delete a tag | Settings → Tags. Renaming rewrites it everywhere; deleting only removes the label, never the item |
| Save tab to read later | `Alt+Shift+S`, right-click → *Save page/link to Read Later*, or the popup button |
| Save selected text as a note | right-click → *Save selection as a note* |
| Write a note | notes are markdown; the editor has a toolbar and a Preview tab. There is no Save button — it saves as you type, because a popup closes as soon as you click elsewhere |
| Clipboard history | off by default: in Settings, turn on capture and click *Allow* on each site, or use *Save from clipboard* in the Clipboard tab |
| Vault | Vault tab → set a master password (cannot be recovered) |
| Fill a login | open the site, then Vault → the item saved for that site → *Fill* |
| Undo a delete | the trash icon on the rail, or Settings → Trash → *Restore* |

Change shortcuts at `chrome://extensions/shortcuts`.

```
tests/                    extension tests: offline sync, markdown, autofill (`make test-ext`)
extension/lib/supabase.js vendored supabase-js 2.118 (MV3 forbids remote code)
mobile/                   Flutter Android app (see mobile/README.md)
```

## Offline
The popup reads through a cache, so it opens with your data when the network is down.
Anything you change offline is queued and synced when the connection comes back; a strip
under the header shows when that is pending. Signing out clears the cache and the queue.

## Notes are markdown now
Notes written before this change are stored as sanitized HTML and carry `format = 'html'`.
They keep rendering correctly; opening one in the editor converts it to markdown and saves it
that way. The Android app still renders the HTML form and has not been taught markdown yet, so
a note edited in the extension will show its markup as literal text there until `mobile/` is
updated to match.
